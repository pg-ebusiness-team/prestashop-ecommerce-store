# prestashop-ecommerce-store
Sklep internetowy oparty na PrestaShop 8.x uruchamiany w kontenerach Docker, wyposażony w automatyczny import danych ze scrapera oraz testy E2E w Playwright. Projekt obejmuje pełną obsługę zamówień, płatności, dostaw oraz analitykę GA4 i integrację z klastrem Docker Swarm.
